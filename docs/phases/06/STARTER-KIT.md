# Phase 06 starter kit

## Existing lab inputs

- Configurable model list discovered from Ollama and optional hosted adapters
- Twenty-one prompts across quick, tool-calling, multimodal, and analyst tiers
- Contestant/judge role selection
- Configurable repetitions, timeouts, rubric weights, and Round 2 rules

## Existing lab outputs

- Live Round 1 heatmap
- Speed chart
- Quality-versus-speed scatter
- Consistency view
- Round 2 ranking
- Response and judge-commentary drilldown
- Persisted JSON results
- Markdown evaluation report

## Discussion worksheet

After reading the results, learners may annotate:

- Which result looks like a utility model?
- Which looks like a fast workhorse?
- Which tasks appear to require a specialist or deep thinker?
- Where was local inference already good enough?
- Where did quality justify a slower or more expensive model?
- How might a future router distinguish those tasks?

This worksheet does not add routing, harness comparison, or reasoning-level implementation to the lab.
