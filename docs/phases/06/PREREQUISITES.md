# Prerequisites — Phase 06

- Phases 00–05 complete
- Node.js and the repository package manager
- Permission to use the selected evaluation data
- Ollama installed and running with the selected local models downloaded
- Approved credentials for any hosted contestants or judges used by the cohort
- The built-in prompt suite available
- Enough disk, RAM, and time for the selected local configurations
- A spending limit for hosted runs

## Safety and policy check

- Classify the workload before sending it to any hosted service.
- Never place credentials in source, exported results, screenshots, or prompts.
- Record provider retention and regional constraints when relevant.
- Use synthetic or approved data when the real workload is restricted.
- Keep a cached run for classroom continuity.

## Staleness warning

Model names, availability, prices, context limits, and routing products change quickly. Refresh examples before teaching. Keep the lab configurable and treat named routing products only as time-stamped discussion examples.
