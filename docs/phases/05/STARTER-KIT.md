# Phase 05 starter kit

## App data

Catalog each skill’s source, revision/hash, files, capability/preference, category, maturity, scripts, permissions, dependencies, supported tools, context estimate, trust state, recommended scope, owner, and review trigger.

## Views

- Catalog and scouting-run diff
- Skills matrix with saved filters
- Complete folder preview
- Evaluation worksheet
- Compare candidates

## Roles

Catalog builder fetches/parses; browser builder presents; scout discovers; evaluator judges. None may publish.
