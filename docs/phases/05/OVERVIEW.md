# Phase 05 — Learner overview

## Today

You will build a repeatable capability-scouting application and learn to judge
external skills and specialized agents before your team adopts them.

## The question

> Would you let this capability instruct an agent that can read your source
> code, run commands, and use credentials?

“It is popular” and “the demo worked” are not sufficient answers. You need the
source, exact revision, full contents, required authority, test evidence,
appropriate scope, and an accountable owner.

## You will do

1. Refresh a catalog from configured public and local sources.
2. Inspect parser failures and changes since the prior run.
3. Search and compare skills and agents by function and risk.
4. Preview every file in a candidate, including scripts and references.
5. Evaluate three exact revisions.
6. Sandbox-test one candidate's trigger and behavior.
7. Reject or restrict at least one candidate.
8. Recommend personal, team/project, or organizational scope.

## You will leave with

- a refreshable catalog and immutable scouting snapshots;
- a searchable capability matrix and revision diff;
- three evidence-backed evaluation records;
- one candidate ready—or explicitly not ready—for Phase 05.5;
- an owner and re-review trigger; and
- a clear mental model for canonical skills and agents versus generated tool
  projections.

## Boundary

This phase scouts and evaluates. It does not install, publish, or approve an
external capability for others. Those are separate authority-bearing actions.

> Discover broadly. Inspect completely. Trust exact revisions. Publish
> deliberately.
