# Prerequisites — Phase 05

## Technical

- Phase 04 work is committed on the continuing learner branch.
- Node.js and the repository package manager are available.
- The selected harness passes `npm run ai:check`.
- GitHub or other configured source access is approved, or the instructor has
  supplied an offline cache.
- Learners can run the application locally without exposing credentials.

## Program

- Read [the skills and agents program](../../ai-program/02-technology-governance/03-skills-and-specialized-agents/README.md).
- Inspect [`ai/functions.json`](../../../ai/functions.json) and one canonical
  skill and agent.
- Identify the organization's allowed source, license, network, and data
  policies.
- Confirm who may evaluate, approve, publish, and revoke capabilities.

## Instructor preflight

Before class:

1. Refresh every source and record its revision and retrieval time.
2. Check rate limits and prepare a known-good offline snapshot.
3. Choose one useful candidate, one ambiguous candidate, and one candidate
   with a teachable risk.
4. Verify that full-file preview exposes scripts and supporting resources.
5. Rehearse a rejected evaluation; do not let all three examples pass.
6. Remove credentials and tokens from demonstration data.

Counts, stars, adopter lists, model support, and tool paths are time-sensitive.
Date every live claim and teach the durable evaluation method.

## Authority boundary

The lab assumes permission to read and evaluate configured sources. It does not
assume authority to install external code, modify the canonical library,
publish to a team repository, or grant production access.
