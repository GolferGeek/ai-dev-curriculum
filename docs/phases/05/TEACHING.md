# Phase 05 — Instructor teaching guide

Open with: skills are third-party behavioral dependencies, not prompt collectibles.

1. Distinguish skills from agents, rules, tools, memory, and code.
2. Walk the corporate handbook in `docs/ai-program/skills/`.
3. Teach scope, precedence, exact-revision approval, and progressive adoption.
4. Predict source/parser/security problems.
5. Build the locator while teaching provenance, triggers, tests, context, and lifecycle.
6. Evaluate three candidates; require a reasoned rejection.
7. Discuss personal freedom versus organizational consistency.
8. Close with the difference between locator and registry; introduce Phase 05.5.

Ask: Would you let this skill instruct an agent using your code and credentials?
