# Demo-grade bar — Phase 05

## Pass

The demonstration passes when:

- at least three configured sources refresh or load from a visibly dated
  offline snapshot;
- every snapshot preserves provenance, exact source revision, retrieval time,
  and content hashes;
- the catalog supports both skills and specialized agents;
- run-to-run diff identifies added, changed, removed, unchanged, and failed
  entries;
- search covers names, descriptions, and content;
- filters include function, kind, source, harness, risk, scope, and trust;
- detail view previews every supporting file and highlights scripts and
  requested authority;
- stable identity and exact revision are visibly distinct;
- three evaluations use the same rubric and include evidence;
- one candidate is rejected or restricted for a defensible reason;
- one candidate has trigger, non-trigger, collision, safety, and outcome test
  evidence;
- every recommendation includes scope, owner, and re-review trigger; and
- no discovery action silently installs or publishes a capability.

## Fail

The demonstration fails when:

- counts or adopter lists are presented as timeless facts;
- stars, source reputation, or visual polish substitute for evaluation;
- raw source content or bundled scripts are hidden;
- exact revision is unknown;
- multiple formats are flattened by discarding meaningful fields;
- “copy,” “export,” or “try” implies approval;
- all candidates are accepted;
- generated harness files become independent sources of truth; or
- a learner cannot explain the reason for the decision.

## Stretch

After the pass bar, consider signed snapshots, parser fixtures for more native
formats, saved evaluation comparisons, or an export package that remains
clearly unapproved.
