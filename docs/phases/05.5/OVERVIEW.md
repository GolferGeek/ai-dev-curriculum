# Phase 05 Part B — Learner overview

## Today

You will improve the Phase 05 locator into an organizational capability
registry. The hard part is not adding a database. It is preserving evidence
while introducing authority, publication, generation, and lifecycle.

## You will do

1. Map the existing static model and prove a recovery point.
2. Create an idempotent SurrealDB schema and migration.
3. Verify record and hash parity before adding features.
4. Persist evaluations, decisions, scopes, owners, expiration, and use.
5. Approve one exact revision for a defined scope.
6. propose a canonical skill or agent through a Git branch and PR.
7. Generate Claude Code, Cursor, and Codex interpretations.
8. Detect an upstream change and require re-review.
9. Supersede, restrict, revoke, or retire a capability.

## You will leave with

- a working registry and migration;
- a reviewable canonical publication flow;
- native projections generated from one source;
- an ownership and maintenance model; and
- evidence that policy follows exact revisions.

> A registry records what the organization trusts, why, where it is used, and
> whether it still earns that trust.
