# Phase 05.5 starter kit

Core records: `skill`, `skill_revision`, `skill_source`, `skill_file`, `evaluation`, `policy_decision`, `installation`, `scouting_run`, `organization`, `team`, `project`, `user`, `tag`, `permission`.

Relationships: revisions, source, tags, permissions, dependencies, conflicts, supersession, evaluation, policy scope, installation, discovery.

Store exact hashes and content snapshots. Model local modifications. Apply schema through version-controlled idempotent `.surql` files under the shared data package.
