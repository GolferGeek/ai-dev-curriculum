# Demo-grade bar — Phase 05.5

Pass when schema and migration are version-controlled/idempotent; catalog parity is verified; exact revisions, evaluations, policy scopes, owners, expirations, and installations persist; refresh detects change; project publication uses a PR; and maintenance identifies stale/re-review/retirement states.

Fail when the database silently replaces Git publication, approval floats across revisions, migration duplicates records, credentials are embedded, or RBAC allows self-approval.
