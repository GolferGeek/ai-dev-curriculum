# Phase 05.5 — Talking points

- Database migration is product evolution, not a rewrite.
- Registry control plane and Git execution contract have different responsibilities.
- Approval belongs to an exact revision.
- Discovery may automate; consequential publication follows authority.
- Local/team/enterprise scope needs RBAC, ownership, and precedence.
- Upstream, reviewed, approved, installed, and locally modified versions may differ.
- Lifecycle includes refresh, re-review, supersession, revocation, and retirement.
