# Prerequisites — Phase 07
## Repository and product

- Phases 00–06 complete; Phase 05 Part B may be completed during the same
  course day as Phase 05.
- One continuing learner branch with the week's verified artifacts.
- Node.js, npm, and Playwright installed.
- The reference app under `completed/apps/ai-program/` builds locally.
- The standard `docs/ai-program/` hierarchy and canonical `ai/` capabilities
  are present.

## Client inputs

- An authorized list of source names and durable locations; source contents
  may remain in protected systems.
- Named candidates for program owner, category owners, approvers, risk owners,
  control owners, and evidence custodians.
- Approved or explicitly unknown answers for harness/model use, data classes,
  agent authority, software-change gates, incidents, exceptions, and review.
- One low-risk repository change suitable for completion and rollback in the
  session.

If client sources cannot be shared, record names and locations only, keep the
affected action restricted, and use the clearly fictional worksheet record for
practice. Never invent an organizational interpretation.

## Safety preflight

- Confirm whether the team is working in the course repository, a sanitized
  clone, or a client repository.
- Identify protected branches, secrets, confidential files, production
  systems, external-message actions, and destructive commands.
- Establish who can approve program content and who can accept residual risk.
- Run the existing build and tests before changes.
- Create or verify a recoverable branch/checkpoint.

## Instructor preparation

- Run and visually inspect the completed reference on desktop and mobile.
- Prepare one healthy trace and one trace with a deliberately missing link.
- Confirm the application shows the curriculum baseline as draft/unassigned.
- Rehearse the advisor's six canonical questions.
- Prepare the fictional GRC fallback and label it visibly as non-policy.
- Confirm a recovery path if a client's local environment or source access
  fails.
