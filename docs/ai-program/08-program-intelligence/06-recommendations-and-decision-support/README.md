# Recommendations and decision support

This node defines how the agent proposes prioritized next actions, options,
tradeoffs, experiments, controls, remediation, or policy changes while keeping
recommendations separate from current decisions.

Recommendations should identify the trigger, affected scope, options, evidence
and uncertainty, security/data/cost impact, migration and rollback, owners,
approvers, validation, outcome measure, and proposed document or capability
changes.

The program agent may prepare a reviewable proposal but never silently approve,
publish, accept risk, or declare the recommendation active.
