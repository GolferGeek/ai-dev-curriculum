# Change monitoring

This node explains what has changed or may require program review, including
accepted decisions, proposals, source or contract updates, provider and model
changes, capability revisions, incidents, control failures, owner changes, and
watchlist developments.

Changes should identify source, retrieval or event date, affected nodes and
scopes, current decision, required review, owner, urgency, and whether the item
is evidence, inference, external terrain, or a proposal.

The program agent reports relevance and impact without treating external change
as automatic company policy.
