# Gaps and missing information

This node identifies decisions, fields, owners, sources, controls, evidence,
links, capabilities, and approvals required by the program but not currently
available or complete.

Each finding should state what is missing, why it matters, affected scope and
action, current restriction, responsible owner or needed authority, severity,
and recommended resolution.

The program agent distinguishes a confirmed absence from information it cannot
access. It never fills a gap with generic guidance, a course default, vendor
material, or model inference.
