# Staleness and expiration

This node identifies records whose scheduled review, evidence period, approval,
exception, evaluation, ownership, version, or underlying assumption is no
longer current.

Staleness combines dates with event triggers: a recently reviewed policy may
still require review after an incident, provider change, new data class, control
failure, or changed obligation.

The program agent states what is stale, why, affected scope, current operating
state, and required owner. It distinguishes review due from restricted,
superseded, and retired states.
