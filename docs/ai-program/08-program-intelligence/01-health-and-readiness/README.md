# Health and readiness

This node defines how the application summarizes whether each category, node,
requirement trace, control, and capability is ready to operate.

Health should be computed from explicit criteria such as approved status,
scope, ownership, evidence, trace completeness, review state, unresolved
findings, exceptions, and validation. Suggested labels are healthy, needs
attention, restricted, unknown, superseded, and retired; organizations approve
their own definitions.

The program agent explains every rating and links its contributing records. It
does not collapse unknown information into a reassuring score.
