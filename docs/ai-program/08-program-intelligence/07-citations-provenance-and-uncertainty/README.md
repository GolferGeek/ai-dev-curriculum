# Citations, provenance, and uncertainty

This node governs how application answers show their basis and limitations so
users can distinguish approved company policy from proposals, external terrain,
examples, evidence, and inference.

Every consequential answer should identify applicable scope, governing files
and decisions, owner, last and next review, evidence links, exceptions,
conflicts, inaccessible information, and a safe next action. Time-sensitive
claims include retrieval dates.

The program agent reports uncertainty directly and never invents owners,
sources, interpretations, controls, evidence, or compliance conclusions to
produce a complete-looking answer.
