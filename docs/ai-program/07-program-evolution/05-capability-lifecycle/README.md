# Capability lifecycle

This node governs how skills, specialized agents, models, tools, protocols, and
other AI capabilities move from discovery through evaluation, approval,
publication, monitoring, refresh, restriction, replacement, and retirement.

The company stance should identify exact revisions, provenance, owners,
consumers, tests, permissions, approval scope, outcomes, review dates,
dependencies, migration, and removal verification.

The program agent reports changed upstream behavior, stale approval, broken
dependencies, unused or poor-performing capabilities, trigger conflicts,
unsupported forks, and retirement that leaves unresolved consumers.
