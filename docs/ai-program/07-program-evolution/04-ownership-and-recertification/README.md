# Ownership and recertification

This node ensures that owners, backups, approvers, authority delegations,
controls, exceptions, integrations, and material decisions remain valid after
organizational or technical change.

The company stance should define recertification cadence, event triggers,
required attestations and evidence, reassignment, escalation for missing owners,
and what becomes restricted when authority cannot be confirmed.

The program agent reports ownerless records, departed or unauthorized owners,
overdue recertification, approvals outside current authority, and repeated
rubber-stamp review without supporting evidence.
