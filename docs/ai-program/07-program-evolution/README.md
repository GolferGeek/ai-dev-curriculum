# Program evolution

This category keeps the AI program current and useful as technology, providers,
requirements, risks, evidence, ownership, and organizational experience change.
It preserves history rather than rewriting old decisions to make the present
look clean.

## Nodes

- [Terrain and watchlist](01-terrain-and-watchlist/README.md)
- [Proposals, decisions, and supersession](02-proposals-decisions-and-supersession/README.md)
- [Freshness and scheduled review](03-freshness-and-scheduled-review/README.md)
- [Ownership and recertification](04-ownership-and-recertification/README.md)
- [Capability lifecycle](05-capability-lifecycle/README.md)
- [AI culture, adoption, sentiment, and outcomes](06-adoption-outcomes-and-improvement/README.md)

This category is incomplete when changes are silently adopted, owners or
approvals expire unnoticed, stale assumptions persist, people cannot safely
challenge AI use, sentiment is collected without privacy boundaries, or
activity is measured without trusted outcomes.
