# Models, providers, routing, and spend

This node governs which providers and models serve each workload, how requests
are routed, what data may be sent, how quality and cost are evaluated, and what
happens when the preferred route is unavailable.

The company stance should link the approved model and provider inventory,
workload and data-class routing, evaluations, provider terms and reviews,
budgets, alerts, limits, fallback routes, retirement plans, and dated model
identifiers.

The program agent recommends only within approved choices. It reports stale
model identifiers, unapproved providers, missing workload evaluations,
uncontrolled spend, and fallback that sends data to a less trusted destination.
