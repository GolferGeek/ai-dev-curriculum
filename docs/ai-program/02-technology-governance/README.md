# Technology governance

This category contains standing and consequential technical decisions about AI
interfaces, models, skills, agents, integrations, protocols, architecture, and
portability. It does not turn every project implementation detail into central
policy.

Technical choices connect to GRC when they affect data, authority, security,
contractual obligations, controls, evidence, cost, or material outcomes.

## Nodes

- [Harnesses and interfaces](01-harnesses-and-interfaces/README.md)
- [Models, providers, routing, and spend](02-models-providers-routing-and-spend/README.md)
- [Skills and specialized agents](03-skills-and-specialized-agents/README.md)
- [Tools, plugins, APIs, and MCP](04-tools-plugins-apis-and-mcp/README.md)
- [Protocols, counterparties, and payments](05-protocols-counterparties-and-payments/README.md)
- [Architecture, dependencies, and portability](06-architecture-dependencies-and-portability/README.md)

This category is incomplete when an approved technology lacks scope, owner,
evaluation, permission boundaries, data handling, review date, or exit path.
