# Triggers, tests, and context

Test:

- Prompts that should trigger
- Prompts that must not trigger
- Collisions and precedence
- Expected steps and output
- Prohibited behavior
- Failure, ambiguity, and permission cases
- Cross-tool compatibility
- Regression behavior after revision

Track metadata cost, full-body size, linked references, redundant instructions, and always-loaded rules. More installed skills can reduce performance. Split oversized skills; compose only when dependencies and precedence are explicit.
