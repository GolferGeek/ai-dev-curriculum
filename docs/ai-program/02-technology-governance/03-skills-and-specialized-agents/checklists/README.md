# Skill and specialized-agent governance checklists

These checklists turn the capability-governance handbook into repeatable review
evidence. They support scouting, evaluation, publication, and retirement
without granting approval merely because a checklist was completed.

- [Scouting](scouting.md)
- [Evaluation](evaluation.md)
- [Publication](publication.md)
- [Retirement](retirement.md)

The organization should record the exact capability revision, reviewer,
applicable scope, evidence location, outcome, approval authority, and review
date with each completed checklist.
