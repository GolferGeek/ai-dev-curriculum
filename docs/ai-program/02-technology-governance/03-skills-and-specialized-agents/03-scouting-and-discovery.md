# Scouting and discovery

Configure approved sources and a refresh cadence. Every scouting run records source revision, time, errors, additions, removals, changed content, new scripts, permission changes, ownership changes, and overlaps with internal skills.

States: discovered, shortlisted, under review, sandbox, approved, restricted, rejected, superseded, retired, update available.

Automatic discovery must not imply automatic installation. Produce a catalog diff and shortlist candidates by relevance, not popularity alone.
