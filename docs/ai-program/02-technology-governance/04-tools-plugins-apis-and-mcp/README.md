# Tools, plugins, APIs, and MCP

This node governs integrations that give an agent access to tools, resources,
prompts, accounts, networks, or data through native APIs, plugins, or MCP
servers.

The company stance should list approved integrations and revisions, operators,
identities, authentication, permissions, accessible resources, data flows,
network destinations, logging, failure behavior, revocation, and review.

The program agent selects the least-authority approved integration and reports
excessive scopes, unknown operators, unreviewed updates, hidden network access,
missing audit events, and unsafe handling of untrusted content.
