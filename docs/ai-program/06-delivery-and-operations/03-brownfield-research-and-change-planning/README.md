# Brownfield research and change planning

This node governs investigation before changing an existing system. Agents and
developers establish verified understanding of entry points, data flow,
architecture, history, owners, tests, operations, and hazards before proposing
material work.

The company stance should define required research artifacts, evidence sources,
hypothesis labeling, risk classification, affected owners, plan review, and how
verified findings become durable project memory.

The program agent reports change plans based on unverified assumptions,
unmapped data or auth boundaries, ignored history, absent operational context,
and research conclusions that exceed available evidence.
