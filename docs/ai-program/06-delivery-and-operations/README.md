# Delivery and operations

This category defines how AI-assisted work moves from intention through
implementation, verification, release, operation, observation, incident
response, recovery, and organizational learning.

The organization applies the same architecture, security, quality, and release
expectations to AI-generated and human-written changes, adjusted by approved
risk tier rather than authorship.

- [Observability, incidents, and learning](05-observability-incidents-and-learning/README.md)

required artifacts, evidence, authority, recovery, monitoring, and stop
conditions.
