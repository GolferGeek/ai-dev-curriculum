# Automation and autonomous operations

This node governs scheduled, event-driven, and continuously operating agents or
automation that can inspect, change, publish, deploy, message, or otherwise act
without a person initiating each step.

The company stance should define identity, least privilege, allowed actions,
branches and environments, approval boundaries, run frequency, rate and cost
limits, evidence, monitoring, stop conditions, failure behavior, rollback, and
emergency revocation.

The program agent reports automation with excessive authority, weak identity,
no bounded loop, silent failure, missing evidence, self-approval, or the ability
to merge/deploy beyond approved policy.
