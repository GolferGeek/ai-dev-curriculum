# Deployment, migration, rollback, and recovery

This node governs how changes enter environments, how state and data migrations
are controlled, and how the organization limits, reverses, or recovers from
failure.

The company stance should define environment separation, deployment authority,
phased rollout, feature flags, migration rehearsal, backups, rollback and
restore procedures, approvals, monitoring, stop conditions, and recovery tests.

The program agent reports irreversible changes without accepted risk, untested
rollback, missing backup verification, unclear deploy authority, absent stop
conditions, and recovery claims unsupported by rehearsal or evidence.
