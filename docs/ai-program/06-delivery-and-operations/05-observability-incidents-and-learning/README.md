# Observability, incidents, and learning

This node defines the signals, records, alerts, and response needed to detect
AI-related failures, investigate them, contain impact, recover service, satisfy
approved notification obligations, and improve the program.

The company stance should link logging and trace rules, privacy and retention,
health indicators, alert ownership, incident classification, containment,
communications, evidence preservation, review, and follow-through.

The program agent reports material blind spots, sensitive telemetry exposure,
unowned alerts, missing incident paths, repeat failures without learning, and
program documents or controls that were not updated after an incident.
