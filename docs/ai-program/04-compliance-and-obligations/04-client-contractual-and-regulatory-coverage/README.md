# Client, contractual, and regulatory coverage

This node shows whether the program covers every approved client, contractual,
regulatory, audit, and assurance obligation relevant to AI-assisted development
without exposing protected source material.

The company stance should provide coverage by client, product, system, data
class, jurisdiction, and source, linking requirements, controls, evidence,
gaps, exceptions, owners, and review dates.

The program agent reports unassessed clients or systems, requirements without
controls, controls without evidence, scope changes not reflected in mappings,
and coverage claims based only on a generic framework or course example.
