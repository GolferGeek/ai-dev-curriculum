# Applicability, interpretation, and scope

This node records the organization's authorized determination of whether and
how a source applies to entities, people, clients, products, repositories,
systems, data classes, locations, or actions.

The company stance should link the approved interpretation, interpreter and
approver, assumptions, scope, effective date, conflicts, unresolved questions,
and review triggers. Sensitive advice may remain in an approved system.

The program agent never invents legal or contractual interpretation. It reports
ambiguous scope, missing authority, conflict, and interpretations that no
longer match the source or system.
