# Compliance and obligations

This category records which approved legal, contractual, client, regulatory,
audit, security, and internal requirements govern AI work. It focuses on
authoritative sources, approved interpretation, applicability, and requirement
coverage.

The program does not interpret law or contracts for the organization. Unknown
applicability remains a visible gap routed to an authorized interpreter.

## Nodes

- [Authoritative source register](01-authoritative-source-register/README.md)
- [Applicability, interpretation, and scope](02-applicability-interpretation-and-scope/README.md)
- [Requirements and obligation catalog](03-requirements-and-obligation-catalog/README.md)
- [Client, contractual, and regulatory coverage](04-client-contractual-and-regulatory-coverage/README.md)
- [Compliance status and limitations](05-compliance-status-and-limitations/README.md)

This category is incomplete when a compliance assertion lacks an authoritative
source, approved interpretation, scope, owner, and current control/evidence
trace.
