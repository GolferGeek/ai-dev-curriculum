# Compliance status and limitations

This node presents qualified status for approved obligations while explaining
what available records and evidence do and do not establish.

The company stance should define statuses such as supported, partially
supported, unsupported, not applicable, unknown, or under review. Each status
links scope, requirements, controls, evidence, owner, assessment date,
limitations, exceptions, and next review.

The program agent never infers certification or legal compliance from documents
alone. It reports missing evidence, expired assessment, unresolved
applicability, material exceptions, and language that overstates proof.
