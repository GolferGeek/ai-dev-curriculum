# Requirements and obligation catalog

This node translates approved source interpretations into stable, sanitized,
addressable requirements linked to risk, controls, evidence, decisions, and
exceptions.

Each requirement should have a stable identifier, source, approved summary,
scope, owner, risk rationale, effective state, review dates, related
requirements, and implementing controls.

The program agent retrieves requirements by system, data, action, client, or
source and reports duplicates, conflicts, orphaned sources, missing scope or
owner, unmapped requirements, and retired requirements treated as active.
