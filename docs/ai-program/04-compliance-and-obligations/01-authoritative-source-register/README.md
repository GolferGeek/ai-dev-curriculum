# Authoritative source register

This node inventories sources that may impose requirements on AI work,
including internal policies, client and vendor contracts, identified laws or
regulatory control sets, audit criteria, and security standards.

Each record should identify source name, type, authority, approved location,
owner or interpreter, covered entities, confidentiality handling, last verified
date, and superseding source. Protected material may remain outside Git.

The program agent cites only approved sources and reports unknown authority,
inaccessible or superseded sources, stale verification, missing interpreters,
and claims with no registered source.
