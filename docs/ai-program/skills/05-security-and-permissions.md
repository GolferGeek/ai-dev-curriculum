# Security and permissions

Review instruction-only content and executable content. Look for exfiltration, unnecessary secrets, broad filesystem access, hidden network calls, destructive commands, approval bypass, prompt-injection exposure, untrusted linked references, supply-chain dependencies, and instructions that weaken other guardrails.

Adopt progressively:

```text
static inspection → isolated test → personal trial → project pilot → enterprise
```

Increase data, tools, and authority only after evidence. A skill may never approve or publish itself.
