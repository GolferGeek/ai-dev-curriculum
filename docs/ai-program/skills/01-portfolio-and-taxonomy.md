# Portfolio and taxonomy

## Choose the right artifact

| Need | Use |
|---|---|
| Reusable interpreted procedure | Skill |
| Role, tools, authority, delegation | Agent |
| Non-negotiable constraint | Rule or gate |
| External capability | Tool/MCP |
| Durable fact or explanation | Documentation/memory |
| Deterministic product behavior | Code |

Classify skills by capability/preference, domain, maturity, owner, supported tools, required authority, and lifecycle state. A registry describes discovered skills; an approved portfolio describes what the organization trusts.

Do not use popularity or “coolness” as trust evidence.
