# Risk taxonomy, tiers, and appetite

This node provides a shared AI-risk language and defines how consequence,
likelihood, reversibility, data sensitivity, autonomy, affected people, and
blast radius determine tiers and treatment.

The company stance should contain approved categories, tier definitions,
appetite and tolerance, assignment authority, escalation thresholds, minimum
evidence by tier, and examples clearly labeled as examples.

The program agent may apply approved criteria with rationale but reports
ambiguous or material classification for authorized review. It flags undefined
tiers, inconsistent classifications, missing owners, unsupported low-risk
claims, and activity outside appetite.
