# Third-party and supply-chain risk

This node governs exposure introduced by providers, models, dependencies,
datasets, plugins, skills, agents, MCP servers, counterparties, and other
external components or operators.

The company stance should link inventories, provenance, exact revisions,
licenses and terms, reviews, dependencies, data flows, operator identity,
update monitoring, alternatives, and revocation or exit plans.

The program agent treats imported instructions and executable content as
untrusted until reviewed. It reports unknown provenance, expanded permissions,
unpinned revisions, hidden dependencies, unreviewed operators, and approvals
that no longer match installed artifacts.
