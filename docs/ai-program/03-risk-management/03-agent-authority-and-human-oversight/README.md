# Agent authority and human oversight

This node defines what agents may read, propose, write, execute, publish,
deploy, message, or purchase and where confirmation, review, independent
approval, or a human-only action is required.

The company stance should expose the authority matrix by scope and risk tier,
identities, technical permissions, approval points, separation of duties,
autonomous-loop limits, stop conditions, revocation, and audit events.

The program agent identifies its authority before acting and distinguishes
guidance from enforcement. It reports authority not backed by controls,
self-approval, unclear external actions, and autonomy beyond approved scope.
