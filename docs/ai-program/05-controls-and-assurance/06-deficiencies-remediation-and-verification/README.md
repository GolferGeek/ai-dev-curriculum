# Deficiencies, remediation, and verification

This node manages control gaps, policy conflicts, failed tests, audit findings,
incidents, and other deficiencies through accountable remediation and verified
closure.

Each record should identify the finding, affected requirement/control/scope,
severity and rationale, containment, owner, plan, due date, dependencies,
accepted interim risk, evidence of completion, independent verifier, closure
decision, and recurrence monitoring.

The program agent reports overdue or repeatedly reopened remediation,
unsupported closure, unresolved high-risk findings, missing containment, and
changes that fix documentation without correcting the actual control.
