# Evidence and retention

This node defines what demonstrates that a decision or control was approved,
implemented, and operated, where that evidence is retained, who may inspect it,
and how sensitive content is protected.

Evidence records should identify the requirement and control, evidence type,
approved location, producer, period, collection method, retention and deletion,
access boundary, integrity checks, reviewer, and limitations. Protected evidence
may remain in an external approved system.

The program agent reports missing, inaccessible, stale, incomplete, or
mis-scoped evidence and distinguishes a document, test result, approval, and
runtime record by what each actually proves.
