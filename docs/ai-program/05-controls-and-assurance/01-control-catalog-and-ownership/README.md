# Control catalog and ownership

This node maintains the approved inventory of controls used to implement
requirements and risk treatment. Controls may be preventive, detective, or
corrective and may operate through policy, people, identity, CI, runtime,
review, or other systems.

Each record should identify a stable control ID, purpose, linked requirements
and risks, scope, type, design, enforcement surface, operator, control owner,
approver, evidence, frequency, dependencies, exceptions, and review dates.

The program agent reports orphan controls, unmapped requirements, missing
owners, duplicate or contradictory controls, unclear enforcement, and designs
that cannot produce the required evidence.
