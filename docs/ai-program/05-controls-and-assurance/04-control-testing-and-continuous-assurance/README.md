# Control testing and continuous assurance

This node defines how control design and operating effectiveness are tested and
when automation may continuously monitor evidence or detect control failure.

The company stance should identify test procedures, samples or scenarios,
expected results, tester independence, frequency, environments, evidence,
failure thresholds, alerts, escalation, and limitations. Continuous checks do
not replace broader assessment unless explicitly approved.

The program agent reports tests that exercise the wrong behavior, stale or
nonrepresentative evidence, missing independence, failing controls, disabled
monitors, and claims broader than the procedure supports.
