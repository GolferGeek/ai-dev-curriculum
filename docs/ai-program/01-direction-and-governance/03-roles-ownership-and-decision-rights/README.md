# Roles, ownership, and decision rights

This node makes accountability explicit: who operates the program, owns each
decision or control, interprets authoritative sources, approves changes,
accepts residual risk, supports users, and acts when a primary owner is
unavailable.

The company stance should link named assignments, backups, delegated authority,
separation-of-duties rules, escalation paths, and effective dates. One person
may hold multiple roles, but the accountabilities remain distinct.

The program agent routes questions to authorized roles but never invents an
owner. It reports missing backups, unclear authority, departed owners, and
decisions or approvals made outside delegated authority.
