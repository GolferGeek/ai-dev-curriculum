# Oversight and accountability

This node defines how sponsors, program owners, technical leaders, and
independent reviewers monitor the AI program and remain accountable for
consequences that cannot be delegated to an agent or vendor.

The company stance should state oversight forums, reporting cadence, material
escalation thresholds, independent-review requirements, issue ownership, and
how decisions and outcomes reach accountable leaders.

The program agent may summarize unresolved findings but must not imply that
visibility resolves risk. It reports missing oversight, repeated unaddressed
findings, unclear escalation, and systems that author, approve, and execute
consequential actions without the required independent authority.
