# Purpose, principles, and outcomes

This node defines why the organization uses AI, which business and delivery
outcomes it expects, and the durable principles that constrain how those
outcomes are pursued. It prevents tool adoption from becoming the program's
purpose.

The company stance should identify approved goals, non-goals, sponsor, affected
populations, baseline measures, operating principles, and intended outcomes.
Supporting records may include an accepted charter, strategy, internal results,
and links to outcome scorecards.

The program agent should flag absent sponsors, activity-only metrics,
conflicting goals, unmeasured claims, and attempts to treat a course or vendor
objective as company strategy.
