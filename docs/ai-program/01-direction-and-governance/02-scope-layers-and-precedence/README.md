# Scope, layers, and precedence

This node defines where a rule applies and how organization, group/client,
project, and personal layers interact. Scope determines whether an answer is
relevant and which rule prevails when sources disagree.

The company stance should identify covered organizations, people, systems,
repositories, data, clients, environments, and actions, together with the
approved precedence and exception model.

The program agent always names applicable scope. It reports ambiguous
applicability, an overlay that silently weakens a higher rule, an unscoped
policy, or a project assumption presented as organization-wide direction.
