## Catalog Description

Small development teams are being asked to deliver more software, faster, with limited staff and budget. AI coding agents can help, but only when teams know how to use them with structure and discipline.

Learning how to code with AI is a perfectly valid direction. This course serves a different need. The focus is learning how to define a business capability, direct an AI agent to create or modify the application, inspect the result, test the workflow, and decide what is ready to use.

For many business applications, the code is not the most important output. The important output is the capability the organization has been waiting for: a dashboard, workflow, integration, customer portal, internal tool, external product, reporting process, or automation that helps the business move faster.

That changes what a backlog means. Instead of only asking "what can we realistically squeeze in this quarter?", small teams can start asking "what useful software could we finally build if delivery were no longer the bottleneck?" The course helps teams move fast enough to revisit ideas that used to feel permanently out of reach.

At that speed, software becomes a way to explore strategy. Companies can dream bigger, test new avenues, prototype new revenue streams, and try new customer or internal workflows much faster than traditional delivery cycles usually allow. The course teaches teams how to do that with enough testing, review, and governance to keep the work grounded.

In this week-long intensive, participants learn a practical AI-assisted development workflow: define the intention, write requirements, create an implementation plan, direct an AI coding agent, verify the result in a browser, run quality checks, and review the work before accepting it.

Participants will work hands-on with modern AI development tools and realistic software projects. The course includes agent-assisted coding, codebase research, testing, browser-based verification, computer-use workflows, debugging, quality scanning, and responsible AI practices for business environments.

Example projects may include internal dashboards, customer portals, workflow trackers, lightweight CRMs, team knowledge bases, invoice or expense workflows, kanban-style project boards, new product prototypes, and browser-tested business web applications.

The course includes suggested applications for each lesson, but those examples are flexible. For private cohorts, lessons can be aimed at the kinds of apps already sitting in the company's backlog.

Advanced capstone options include an agent-to-agent protocol dashboard, a skills library/browser, and an LLM/model comparison lab.

## Current Tool Capability Language

Use this language when the audience is technical:

The course is tool-agnostic. Participants use whichever AI coding agent they already pay for — Claude Code, Cursor, Codex, or Claude Desktop — and the workflow is the same across all of them; the tool matters less than the discipline.

Participants will use modern AI coding agents to work with local repositories, edit files, run commands, inspect rendered web apps, test user flows in a browser, and review implementation changes. The course covers three complementary ways to verify running software — in-app browsers, Playwright for automated tests, and computer use — including emerging workflows such as Codex in-app browser testing, Codex computer use, Claude Code browser automation, and Claude computer-use workflows where available. Specific browser and computer-use features vary by tool.

For private company cohorts, the course can include a supervised setup day using the company's own codebase. This can cover repository orientation, local development startup, tool permissions, browser verification, and selection of first AI-assisted backlog items.

This codebase setup option is backed by 25 years of instructor experience in large codebases, where the first job is understanding the existing system well enough to make safe, useful changes.

Use this language when the audience is business-oriented:

Participants will learn how current AI development tools can help create and modify business applications, inspect errors, test web workflows, and complete development tasks under human supervision.

Companies may also schedule dedicated setup time to apply the workflow to their own software environment.

AI tooling will keep changing after the course. Organizations should plan to stay current internally or schedule occasional short refresh sessions as needed; this is not intended to become a long-term consulting dependency.
