# Phase 05.5 — Lesson Plan

**Arc:** Existing app → schema and migration → registry policy → exact-revision publication → upstream-change re-review.

Teach that the first app proved usefulness; the second build makes it organizational. SurrealDB is the shared control plane for catalog, revisions, evaluations, policy, and installations. Git remains the review surface for skills that instruct agents inside a project.

During the build, discuss migration parity, idempotency, local/team configuration, RBAC, self-approval prevention, hashes, forks, dependencies, conflicts, expiry, and retirement.

Close by tracing one candidate through discovery, evaluation, approval, project PR, update detection, and re-review.
