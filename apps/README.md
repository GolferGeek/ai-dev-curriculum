# Learner application workspace

Build course applications here.

This directory intentionally begins without completed applications so every
learner can use one continuing branch and create their own implementations
throughout the week.

Finished references are available under [`completed/apps/`](../completed/apps/README.md).
Use them when the instructor asks you to compare behavior, recover from a
blocked build, or study a complete implementation. Do not copy a reference and
present it as lab work.

New JavaScript or TypeScript applications created directly under `apps/` join
the root npm workspace automatically.
